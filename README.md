# Woolworths Web Development Project (Part 3 Submission)

## Overview
This repository contains a dynamic, fully functioning website prototype for Woolworths South Africa, constructed using modern semantic HTML5, CSS3, dynamic JavaScript, Leaflet mapping APIs, and light-box galleries[cite: 2, 3, 4, 7, 8].

## Changelog (Part 2 Feedback Integration)

### Fixed Issues & Enhancements
- **Enhanced Form Handling**: Refactored `enquiry.html` logic to calculate estimated dynamic responses upon client-side validation[cite: 7].
- **Dynamic Content & Sorting**: Integrated `dynamic.js` to render product cards dynamically, enabling live filtering and price sorting[cite: 3].
- **SEO Optimization**: Included explicit OpenGraph tags, JSON-LD schema, meta descriptions, and clean URL structuring across all pages[cite: 4, 5].
- **Interactive Leaflet Map**: Added Leaflet.js map integration on `contact.html` targeting store locations[cite: 2].
- **Security Protocols**: Added client-side input sanitization checks and strict form validations[cite: 6, 8].
